No server, no cloud, no trust. Paste a document sha256; this page fetches the bytes from the public evidence repo (raw.githubusercontent.com), hashes them in your browser with crypto.subtle.digest("SHA-256"), and tells you whether the bytes are the file the hash names. It also shows the court source for that document from /data/official_sources.json (561 documents; 31 with a recorded JIMS URL, the rest by citation route).

Why the GitHub copy: the official JIMS servlet requires a court login and will not serve anonymous requests, so the court link is the authority and this hash-checked copy is the convenience. Compare the two, do not confuse them.

How to do it without this page

curl -sL https://raw.githubusercontent.com/NikoPikoFriko/the95xrecord-evidence/main/sha256/<sha256>.pdf -o f.pdf
sha256sum f.pdf   # should print <sha256>  f.pdf

The repository sets .gitattributes * -text, so a clone does not rewrite these bytes on Windows (this station has core.autocrlf=true system-wide, which would otherwise corrupt text files). Do not compare GitHub's raw ETag with the hash: it is a git blob digest, not a SHA-256 of the content.
